## 2. Interpretation and constraints (main session, stated to the owner 2026-10-06)

- **Item 4** — read as: a **draggable divider** between the two Find lists that resizes their heights (owner may
  correct). Each list scrolls on its own; the divider is keyboard-operable (ADR-021 a11y).
- **Item 5** — hide the pane's main scroll bar while keeping wheel / touch / keyboard scrolling. Inner lists (Find)
  scroll on their own.
- **Item 6** — the down arrow and X are **Office's own title bar**: an add-in cannot place controls there. The button
  goes in the add-in's toolbar beside the "⋮" menu. Width uses `Office.extensionLifeCycle.taskpane.setWidth`
  (TaskPaneApi 1.1) whose limits are web 330-500 px, Windows 86 px-50% of the window, Mac 270 px-50%; a value outside
  the limits is **silently ignored** (task 095 note). So "3x" = the widest the host accepts, up to 3x the default;
  collapse returns to the round-4 default (+75 px). Where the API is unsupported the button is not shown (NFR-10).
