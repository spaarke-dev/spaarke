## 2. Findings that shape the work (from code, 2026-10-05)

- **Fields (item 3)** — `sprk_matter`: name `sprk_mattername`, description `sprk_matterdescription`, Practice Area =
  lookup `sprk_practicearea` → `sprk_practicearea_ref`, Matter Type = lookup → `sprk_mattertype_ref`.
  `sprk_project`: `sprk_projectname`, `sprk_projectdescription`, Project Type = lookup → `sprk_projecttype_ref`.
  `sprk_invoice`: `sprk_name`, `sprk_description`. Assigned To Internal = `sprk_assignedtointernal`, written by the BFF
  as a **contact** lookup (`RecordCreationService.cs:221,280`); `docs/data-model/sprk_matter-related-tables.md:23` says
  systemuser — verify against live metadata before building.
- **Server today** — `QuickCreateRequest` carries Name, Description, MatterTypeId (+ source record for field mapping);
  no practice area, project type or assignee. The server sets Assigned To Internal to the maker's contact unless field
  mapping set it. Invoice uses a separate minimal path. → item 3 needs a BFF change (request fields + lookup lists).
- **Shared library** — `LookupField` (`Spaarke.UI.Components/src/components/LookupField`) is host-agnostic
  (`onSearch` injected) and can be the contact picker. The shared `CreateMatterWizard` / `CreateProjectWizard` /
  `CreateInvoiceWizard` steps are NOT usable as-is: they write through an OData-shaped `IDataService` and carry hidden
  host dependencies (`discoverNavProps` calls `/api/data/v9.0/EntityDefinitions`; `Xrm` frame walking).
- **Item 6 vs an earlier decision** — round 3 chose "Save re-enables on document edits" (task 094): after a save, the
  next edit offers Save (= new version). Removing Save entirely would remove that; see the open question.

## 3. Owner decisions (2026-10-05)

| Question | Decision |
|---|---|
| Shared library (spec ADR-012) | Reuse by default: exact-path imports, never the barrel; `Xrm`-bound components get made host-agnostic, not copied. Spec rows ADR-012 + ADR-044 amended. |
| Share link | Links open the **Spaarke record**; external users open the file from the external access platform. Task 098: honest refusal on the route + the composer's Link inserts the record link. |
| A. Save after a save | No Save until the document is edited; then Save = new version. Cancel / Open Document removed from the post-save view. |
| B. Create fields | Assigned To prefilled with the user's contact, **optional**. Practice Area **required** for a Matter (like Matter Type). |
| C. Create form | Built from shared field components (`LookupField` + dropdowns), creating through the BFF quick-create (WP-3). The shared Create*Wizard steps are not reused (direct Dataverse writes, `Xrm`). |

create fields, BFF + pane). 099 and 100 both edit `RelatedToPicker.tsx` / `SaveFlow.tsx`, so they run in sequence;
098 is independent.
