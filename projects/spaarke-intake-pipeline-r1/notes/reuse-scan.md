## Plan-level duplication check

- **No capability duplicates an existing one.** The two places that looked close are:
  - **The invoice pipeline (orchestration):** not reusable as code (no generic types, and frozen until UAT). Its rules are copied, and invoice later becomes a harness of the new orchestrator (FR-22), which removes the duplication instead of adding to it.
  - **Two suggest-then-confirm surfaces** (triage hint vs Job B): resolved by the owner choosing Job B, so no third surface is added.
- **No new package in the BFF.** The engine runtime lives in its own container (Python + `lxml`), and the BFF publish size is unaffected by it.
- **No index row says "extend X" that this plan ignores.** Index rows 6 (jobs) and 12 (communication send) are both used as the extension points.
