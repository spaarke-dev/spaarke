# SpaarkeAI Tuning and Feedback R1

(skeleton — design.md and spec.md to be produced via /design-to-spec)

Embedded AI improvement for the Spaarke AI platform: day-to-day user confirmations and corrections become labeled data that measurably improves AI capabilities, with an admin front end to measure, compare and tune them — without Microsoft Foundry's portal.

Spun out of eBilling R1 (owner decisions D-61, D-64 in `projects/ebilling-r1/notes/decisions-log.md`). eBilling R1 does **not** depend on this project; it is this project's first data source.
