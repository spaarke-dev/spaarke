## 2026-09-25: Dataverse plugins — current state + alternatives (ADR-002 revisit input)
**Question**: Current plugin authoring/registration/ALM state, MI for plugins, alternatives, and what only in-transaction plugins can do, for an ISV that mostly bans plugins.
**Findings**:
- BUILD: still .NET **Framework** only; .NET Core/5+ plugins explicitly UNSUPPORTED. NEW: docs commit 2026-07-10 (#12193 "sandbox: Add .NET Framework 4.8 support") + 2026-07-16 revision → supported = 4.6.2 through 4.8, plugins "should target 4.8" (supported-customizations ms.date 2026-07-16). A "Q4 2026 rollout" claim appears only in search-engine summaries — NOT found in docs source; unverified. .NET Fx 4.6.2 EOS 2027-01-12.
- Plugin packages (NuGet dependent assemblies) = the supported path; "Microsoft doesn't support ILMerge"; signing not required in packages; limits: 16 MB/assembly, no custom workflow activities, no unmanaged code, package name+version immutable once created, SDK-style csproj required, don't depend on sandbox System.Text.Json (ship it in package). 1000 plugin types ≈ 15-min import.
- Sandbox: 2-min hard limit for whole message op; MS says keep plugin ≤2 s; HTTP/HTTPS only, no IPs/localhost, DNS names only, egress from `PowerPlatformPlex` tag. Best-practice list (updated 2026-08-20): no ExecuteMultiple/ExecuteTransaction, stateless, no parallel threads, KeepAlive=false, set timeouts.
- MI for plugins: GA 2025-08-31 (preview 2024-08-06). `IManagedIdentityService.AcquireToken(scopes)`. Requires Authenticode-signing the assembly/nupkg with a cert; FIC v2 subject = `/eid1/c/pub/t/{b64urlTenant}/a/qzXoWDkuqUa3l6zM5mM0Rw/n/plugin/e/{environmentId}/i/{issuerHash}/s/{subjectHash}` → ONE FIC PER ENVIRONMENT; Entra caps FICs at 20 per app/UAMI → ISV scaling issue. managedidentity record created via Web API POST + PATCH bind to pluginassembly/pluginpackage. `pac managed-identity` verbs (CLI ≥2.8.1; not Linux, not UAMI).
- serviceendpoint table (ms.date 2026-09-18) now has AuthType 9=Managed Identity + ManagedIdentityId lookup, KeyVaultReferenceId, and Contract 9=Event Grid (SchemaType EventGrid/CloudEvents), 10/11 data-lake/container storage — sparse/no how-to docs found (treat as undocumented/preview).
- Low-code: instant low-code plugins DEPRIORITIZED → replaced by "functions" (still preview, page 2025-02); automated low-code plugins still PREVIEW (page 2026-05-08). Background operations still preview (since 2023); same 2-min limit.
- ALM: steps are separate solution components (must add each); secure config NOT exported; assembly major/minor bump = NEW assembly, old steps keep pointing at old one (manual repoint); build/revision = in-place. Patches can't delete components. Custom API: set IsCustomizable=false + IsPrivate=true before ship; main-op plugin can't take config; AllowedCustomProcessingStepType None/AsyncOnly/SyncAndAsync (immutable). Solution checker plugin coverage now only meta-rules on step registrations (dup reg, no filtering attrs, Retrieve/RetrieveMultiple) — no IL code analysis listed.
- Webhooks: 60 s timeout, 1 retry only on 502/503/504, 256 KB payload trim, sync-capable (rollback on failure but can't recall request). Service Bus: async only, 192 KB trim, durable retries via async jobs. Elastic tables: NO transactions — only PreValidation can reliably block.
- Testing: FakeXrmEasy v2+ commercial (RPL/non-commercial/commercial triple license; v1 MIT); XrmMockup365 (MIT, Delegate); DLaB.Xrm (source-only pkg, DI-for-plugins, XrmUnitTest).
**Sources**: learn build-and-package (2026-07-02); supported-customizations (2026-07-16) + GitHub MicrosoftDocs/powerapps-docs commits 82d5988/#12193; set-up-managed-identity (2026-06-15); release-plan 2025wave1 MI plug-ins; access-web-services (2026-06-24); analyze-performance (2026-08-20); best-practices/business-logic (2026-08-20); register-plug-in (2026-04-27); custom-api (2026-08-03); business-events (2026-02-11); use-webhooks + azure-integration (2026-03-31); elastic-tables (2026-08-04); low-code-plug-ins (2026-05-08); functions-overview (2025-02-03); reference/entities/serviceendpoint (2026-09-18); use-powerapps-checker (2026-08-03); pac plugin ref (2026-02-25).
**Open questions**: whether 4.8 sandbox is universally rolled out yet; cross-tenant FIC pattern for ISV (identity in customer tenant vs publisher tenant); is `managedidentity` solution-aware; Event Grid / MI service-endpoint docs; does pac plugin init now default to net48.
**Repo note**: Spaarke's only plugin (`src/dataverse/plugins/Spaarke.CustomApiProxy`) is net462, strong-named, ILRepack-merged (MS-unsupported), stores client secret in a Dataverse row, already `[Obsolete]` for ADR-002.
