## 2026-11-23: G9 Spaarke runtime agent (custom engine agent) viability

**Question**: Can a Spaarke-orchestrated custom engine agent appear in Chat/Teams/Word/Cowork, with SSO/OBO (incl. Work IQ), secret-free, and at what licence cost?

**Findings**:
- **Surfaces**: CEAs listed in Copilot Chat + Teams (GA). Word/Outlook CONFLICT: Learn known-issues (ms.date 2026-11-16) says "not supported in Outlook, Word, Excel, PowerPoint, Edge"; but MC1168289 (2025-10-08, GA, Copilot Studio/AI Toolkit CEAs, Insert action) and release notes 2025-12-10 (Word/Excel [Web]) and 2026-11-17 (Outlook [Web]) say supported. Cowork: no CEA support documented (DAs in Cowork = Frontier private preview). Copilot handoff to CEA = dev preview (2024 page). CEA limits in Copilot: no file attachments/downloads, no proactive, no prior-chat context on @mention, partial citations, no sensitivity labels.
- **Licence**: prerequisites table (2026-11-16) — CEAs available in Copilot Chat with NO Copilot licence and no UBB; cost = own hosting + Bot Service. Work IQ separately metered (Copilot Credits, $0.01; Tools API 0.1 credit/call; Chat/Context variable).
- **Agent 365** = governance/registry/identity control plane (GA 2026-05-01, per-user licence), SDK "doesn't create or host agents". Notifications/Word-comment @mention + agent user account = Frontier preview only. A365 OBO observability doc: "Custom engine agents use standard app registrations with Azure Bot OAuth connections, not the agentic identity chain."
- **Auth/secret-free**: Bot Framework SDK archived (support ended 2025-12-31) -> Agents SDK (stable 1.9.205; BFF pins 1.0.1). Azure Bot still required for SSO/OAuth ("Azure-managed ACS registration"). Bot type must be "Single Tenant" (works multi-tenant via app reg signInAudience); UAMI bot type legacy; runtime auth via MI-as-FIC OK. BUT Bot OAuth connection with FIC: "Only Single Tenant Supported... multitenant coming soon"; Agents SDK MSAL FIC/MI = single-tenant configs only. Cross-tenant => secret/cert.
- **Work IQ**: A2A/REST/remote MCP GA (06-16); `retrieve` public preview; Foundry Work IQ tool page titled preview but says standard MCP integration GA. NEW scopes WorkIQ.Read / WorkIQ.Act (permissions 2026-10-30) beside WorkIQAgent.Ask. Delegated-only, OBO explicit (A2A quickstart: confidential client + OBO). `iss` must be user's home tenant. Federated/synced connectors participate if user connected them in Chat (connectors page 2026-11-18). retrieve: inline citations + per-source metadata + sensitivity labels; security-trimmed. No documented latency/quotas (429 pass-through only). Agent 365 SDK FAQ (10-15) contradicts: "Work IQ MCP is in preview and requires a Copilot licence" (refers to A365 per-workload tooling servers).
- **Code**: `/api/agent/message` takes custom `AgentMessageRequest` JSON under the BFF Entra JWT; no CloudAdapter / `/api/messages`; `SpaarkeAgentHandler` is not registered; `AgentTokenService` OBOs the HTTP Authorization header (would be a Bot Connector token on a real channel).
