## 2026-09-01: AI-inside-Word legal landscape + MCP acceptance (strategy input)

**Question**: What do legal-AI leaders actually ship inside Word, and can third-party Word add-ins consume external MCP servers (load-bearing for Spaarke's "bring-your-own-add-in + Spaarke MCP layer" prong)?

**Findings**: (1) Every serious vendor ships an Office.js task-pane add-in writing **native Word Track Changes** (Harvey documents its mechanism publicly: OfficeJS edits + word-level diff → tracked changes; agentic doc-wide edits raised accept-rate 40%). (2) **MCP is now the legal-AI integration standard**: iManage MCP server (May 2026, "substrate beneath AI tools"), NetDocuments ndMAX MCP (Apr/May 2026), TR CoCounsel↔Claude MCP (May 2026), iManage+TR partnership (Aug 2026). **Legora is a real MCP CLIENT** (Feb 2026: DMS/CRM/e-sign/custom firm MCP servers, incl. proprietary file-transfer extension); **Harvey ships an MCP SERVER** (5 tools, OAuth, Claude/Gemini/M365 Copilot clients) AND is now operationally an MCP CLIENT — its "MCP Connector Library" help article (help.harvey.ai/articles/joining-harvey-mcp-connector-library, live as of 2026-09-01) onboards third-party remote MCP servers with hard requirements: OAuth 2.1 + PKCE(S256), RFC 8414 AS metadata, RFC 9728 PRM (all REQUIRED), DCR optional; workspace admin must enable each connector; Harvey may not prompt before write actions. [CORRECTED 2026-09-01 by [[mcp-ecosystem-publishing-2026-09-01]] — earlier "client = roadmap-only" read was based on the Dec 2025 blog alone.] Spellbook/Definely/Protégé show NO MCP-client evidence. (3) **Microsoft shipped its own Legal Agent in Word** (Apr 30 2026, Frontier, Claude models, playbook review + tracked-change redlines, $30 Copilot license) — commoditizes baseline redlining; Agent Mode GA in Word Apr 2026, default at Build 2026; Anthropic is a Microsoft subprocessor since Jan 2026. Robin AI collapsed (failed ~$50M raise; Microsoft acqui-hired 18+ incl. CTO Carina Negreanu into the Word team). (4) **M365 Copilot declarative agents support MCP GA** (dynamic tool discovery rolling out Jun–Jul 2026) → a Copilot declarative agent consuming Spaarke's MCP server surfaces in Word Copilot chat WITHOUT Spaarke building a Word add-in — the strongest concrete path for prong 1. (5) Table stakes: native TC redlining, playbook review, clause/precedent retrieval, DMS grounding, SOC2 + no-training. Differentiators: agentic doc-wide edits, research-grounded citations in-pane (rare: Harvey/CoCounsel), MCP-client openness, matter context. Firms explicitly moving to "stack of specialized agents" over one vendor (Macfarlanes quote) with DMS-as-MCP-substrate as the shared layer — Spaarke's data-layer thesis is validated, but via Dataverse+SPE MCP being consumed by Legora/Claude/Copilot, NOT by Harvey/Spellbook (no client evidence).
