# Word vs Cowork plugin kinds; Harvey/Legora packaging; Copilot Tuning surfacing (2026-11-02)

**Question**: Are there separate plugin kinds/targeting for Copilot in Word vs Cowork/Chat; how did Harvey/Legora reach Word but not Cowork; can skills that only call remote MCP tools run in Word; where do Copilot Tuning agents surface?

**Findings** (C cited, O consistent with tenant observation, I inference, U unknown)
- **No targeting field** (C, prior note: `agentSkills[]` = `{folder}` only). The distinction is by *capability*: **federated connectors** (MCP, user-level OAuth/Entra SSO, admin in Copilot > Connectors > Your connections) are documented for Copilot Chat, Agents, Cowork, **Copilot in Word/Excel/PowerPoint/Outlook**, and Researcher (C federated-connectors-overview 2026-10-19/10-28). "Installed for and agent sharing settings don't apply to federated connectors" - they appear once allowed + enabled + staged + licensed, no per-user install (C). Plugin *skills*: "host support vary by Microsoft experience" (C), Word has no documented skill runtime.
- **Harvey/Legora**: Gallery "Legal + HR" lists Harvey, Harvey AU, Harvey EU, iManage Work, NetDocuments US, Litera, LegalZoom, Relativity, Everlaw (C). Cowork available-plugins lists Harvey (x3, "AI-powered legal assistant in Microsoft 365 Copilot" = exact Word string), "Legora for Copilot", HighQ, Bloomberg Law, DeepJudge, iManage, NetDocuments MCP (C 2026-10-26/29). Harvey MCP tools: ask_harvey, ask_with_knowledge_source, list_knowledge_sources, list_vault_projects, ask_about_vault; Streamable HTTP + per-user OAuth; MS setup = admin center Copilot > Connectors > Your connections > approve/enable (C developers.harvey.ai, undated). Word's Harvey "Skills" = those 5 names kebab-cased (O+I): either Harvey ships 5 thin SKILL.md wrappers, or Word labels static MCP tools as skills - U. Harvey also ships a DA "@Harvey" agent since 2026-06-16 (S). LexisNexis Protege = custom DA in M365 Copilot incl. Word via Marketplace (S, 2026-06-04); no TR CoCounsel M365 item found.
- **Word-yes/Cowork-no** explained best by acquisition model (I): Word lists every tenant-available connector/plugin; Cowork's Plugins page shows *added* plugins - partner ones must be added from **Add plugins > App Store / All plugins** (C cowork-available-plugins note). Chat shows federated connectors under **... > Settings > Sources**, not the Plugins tab (C).
- **Skill-calls-MCP pattern**: plugin = `agentSkills[{folder}]` + `agentConnectors[{id, displayName, description, toolSource.remoteMcpServer{mcpServerUrl, authorization{type, referenceId}, mcpToolDescription{file}}}]` (C configure-plugin-mcp-servers 2026-10-28; cowork-manage-plugins sample). Auth types: None, OAuthPluginVault, ApiKeyPluginVault, DynamicClientRegistration (Entra has no DCR), AzureKeyVault, ConnectionVault (devPreview); Cowork supports only None/OAuthPluginVault/ApiKeyPluginVault and requires a static tool-description file (C). Redirect `https://teams.microsoft.com/api/platform/v1.0/oAuthRedirect`. Skills "can call approved tools or scripts when the target experience supports them" (C plugin-type-skills). Execution of such skills in Word: U.
- **Custom federated connector** = documented route for Spaarke *tools* in Word: admin center Copilot > Connectors > Gallery > Created by your org > Create a new connector > Connect to MCP server; auth Entra SSO (SSO registration ID from Teams Dev Portal) / OAuth 2.0 / none; write tools allowed with per-tool user approval; staged rollout; governed by "Allow agents and plugins built by your organization" (C set-up-custom-federated-connectors 2026-10-19/10-28). Tools only - no SKILL.md instructions.
- **Admin pages**: plugins/skills = Agents > Tools (Plugins, Registry > Upload, Requests); Cowork plugins also findable in Agents > All agents ("some agents also function as Cowork plugins"); tenant test via Manage apps > Upload custom app; connectors = Copilot > Connectors; ceilings = Agents > Settings > Agent and plugin access / User access (C). Admin deploy of our zip reaches Cowork (C) and PowerPoint org skills (C prior); Word U.
- **Copilot Tuning**: templates built in Agent Builder; tuned agents "shared with eligible users"; used via "Microsoft Copilot app or Copilot Chat in Microsoft Teams" (C overview 2026-06-03/10-31). Doc Validation: start chat with agent, upload doc, agent returns a .docx with inserted comments; only owner tunes, others use (C). Not automatic in general chat; no Word-pane or Cowork surfacing documented (U; DAs generally appear in Word "All agents", prior C). MC1454393 (2026-08-14): Tune disabled by 2026-08-20 for Writing/Summary/Style/Validation/Expert QA; Optimization retired; moves to Copilot Studio skill-based tuning, preview Sept 2026, GA Dec 2026; existing agents keep working.
