# Capability Index — concept → canonical component

> **Purpose**: find the component to extend when you know *what* you want to do but not what it is called. Pattern files (`.claude/patterns/INDEX.md`) say *how*; this table says *which*.
> **How to use**: before writing `<existing>` (task-create Step 3.5.6) or reviewing reuse (code-review Step 6.6), scan the Capability and Synonyms columns. Cite `CAPABILITY-INDEX row N` plus file:line, or `CAPABILITY-INDEX: no row` plus the Grep you ran.
> **Two answers**: where a row names two components, the repo has no single canonical one yet. Do not pick one silently; say which and why.
> **Maintenance**: a PR that adds a canonical component, or changes one's path or extension point, updates its row in the same PR. Paths are backticked repo paths, checked by `scripts/quality/Test-InstructionPaths.ps1`.
> **Last verified**: 2026-11-11 (reuse-governance-tightening-r1 task 001), every path and symbol by Grep/Glob.

## Known overlaps (found while verifying, 2026-11-11)

These are facts, not decisions. They are where a second implementation already exists beside the canonical one; extend the row's component, not these.

- **Row 3** — `src/client/pcf/shared/utils/environmentVariables.ts` keeps a private `normalizeBffUrl`.
- **Row 5** — `src/client/shared/Spaarke.UI.Components/src/services/FieldMappingService.ts` and `src/client/shared/Spaarke.UI.Components/src/services/FieldMappingHandler.ts` sit beside the BFF field-mapping endpoints.
- **Rows 6–7** — 21 BFF classes derive directly from `BackgroundService` (the job processor itself among them); several are hand-rolled timers that predate ADR-052 (e.g. `src/server/api/Sprk.Bff.Api/Services/Communication/DailySendCountResetService.cs`, `src/server/api/Sprk.Bff.Api/Services/Jobs/ScheduledRagIndexingService.cs`). ADR-052 forbids new ones; it does not require migrating these.
- **Row 15** — `src/server/api/Sprk.Bff.Api/Services/Ai/RagIndexingPipeline.cs` is a second chunk → embed → index path (knowledge + discovery indexes), used by the session-files upload in `src/server/api/Sprk.Bff.Api/Api/Ai/ChatDocumentEndpoints.cs`.
- **Row 18** — 10 endpoint files under `src/server/api/Sprk.Bff.Api/Api` set `text/event-stream` by hand; there is no shared SSE writer.
- **Row 23** — three other components are also named `LookupField` (in `CreateMatterWizard`, `EmailStep` and `RecordHeader/fields`).
- **Row 24** — `ChoiceModal` (a `SprkModal` preset) overlaps `ChoiceDialog`.
- **Row 28** — `src/client/external-spa/src/registry/widgetRegistry.ts` and the output/source registries in `src/client/shared/Spaarke.AI.Outputs/src/types/widget-types.ts` are separate widget registries.
